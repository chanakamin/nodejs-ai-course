# קורס פיתוח צד שרת ב-Node.js (מונחה AI)

אתר הקורס מבוסס VitePress.

## צפייה באתר הקורס אונליין
`https://chanakamin.github.io/nodejs-ai-course/`

## הרצה מקומית במחשב (ללא תלות בסינון רשת)
```bash
npm install
npm run docs:dev
```
לאחר ההרצה יש לפתוח בדפדפן את הכתובת שמופיעה בטרמינל (`http://localhost:5173/nodejs-ai-course/`).
